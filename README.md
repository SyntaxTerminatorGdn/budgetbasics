# BudgetBasics

BudgetBasics is a responsive, client-side budgeting education site built with React, Vite, CSS, and JSON content. The calculations and sample records are for learning only. Contact and feedback forms do not send or save submissions.

## Run locally

Requirements: Node.js 20.19+ or 22.12+ and npm.

1. Extract or clone the project and open a terminal in the project folder.
2. Install the locked dependencies with `npm ci`.
3. Start the development server with `npm run dev`.
4. Open the local URL printed by Vite (normally `http://localhost:5173`).

To create and preview the production build, run `npm run build` and then `npm run preview`. Vite serves the production output from `dist/`.

## Main folders

- `src/` — React interface, application logic, and responsive styles.
- `data/` — Pre-populated JSON content, examples, tips, and test data.
- `public/` — Static resources, including the printable student budget checklist.
- `assets/` — Source image and logo assets.
- `docs/` — Project report and manual validation scenarios.

## Data and privacy

Expenses and calculator values are held in browser memory for the current session. Theme, location, and the local demo visitor count use browser storage. They are not transmitted to a server. The visitor count is local to this browser and is not a global site-traffic counter.

## Before submission

- Add the real team names and roles to `data/about.json` before submission.
- Add official social-profile URLs to `data/contact.json` if the project has them; otherwise leave the list empty.
- Record and include the required MP4 demonstration video. The project report includes a scene checklist; this repository does not contain a screen recording.
- Review and run the manual scenarios in `docs/test-cases.md` on the target browsers and devices. Do not treat the expected results as executed test results.
